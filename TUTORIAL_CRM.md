# 📖 Guia do Usuário - AtendZappy CRM

Este documento fornece um passo a passo detalhado sobre as principais funcionalidades do sistema para garantir uma operação eficiente e organizada.

---

## 1. Como Conectar o WhatsApp

Para começar a receber e enviar mensagens, você precisa parear seu celular.

1. No menu lateral esquerdo, clique em **Canais** ou **Conexões**.
2. Clique no botão **Adicionar WhatsApp**.
3. Preencha o nome da conexão (ex: "Suporte") e selecione as filas que este número atenderá.
4. Clique em **Salvar**.
5. Um **QR Code** será gerado. Abra o WhatsApp no seu celular, vá em **Aparelhos Conectados** > **Conectar um Aparelho** e escaneie o código na tela.
6. Aguarde o status mudar para **"CONECTADO"**.

---

## 2. Como Cadastrar um Cliente

Você pode cadastrar contatos manualmente ou deixá-los serem criados automaticamente ao receber uma mensagem.

1. Vá ao menu **Contatos**.
2. Clique no botão **Adicionar Contato**.
3. Um modal será aberto com os campos necessários.

---

## 3. Campos a serem Preenchidos (Checklist)

Para uma gestão de dados eficiente, preencha sempre:

* **Nome**: Nome completo ou identificação do cliente.
* **Número**: Telefone com código de área (Ex: 5511999999999).
* **E-mail**: Essencial para integrações e comunicações formais.
* **Tags**: Adicione etiquetas para filtrar interesses (ex: "Lead Quente", "Produto X").
* **Carteira/Vendedor**: Atribua o contato a um usuário específico da equipe.

---

## 4. Como Agendar no Google Calendário através do CRM

Se a integração estiver ativa, você pode marcar reuniões sem sair da conversa.

1. Dentro do chat com o cliente (Ticket), procure pelo botão/ícone de **Agenda** ou **Integrações**.
2. Clique em **Agendar no Google Calendar**.
3. Defina o **Título**, **Data**, **Horário de Início** e **Término**.
4. O CRM sincronizará o evento diretamente com a sua conta do Google, e você pode optar por enviar o link do convite ao cliente.

---

## 5. Como Agendar uma Mensagem Automática

Útil para lembretes de cobrança ou acompanhamento pós-venda.

1. No menu lateral, clique em **Agendamentos**.
2. Clique em **Novo Agendamento**.
3. Selecione o **Contato** desejado.
4. Escreva a **Mensagem** que será enviada.
5. Escolha a **Data e Hora** exata do disparo.
6. Clique em **Salvar**. O sistema fará o envio automático no momento programado.

---

## 6. Como Movimentar o Cliente dentro do Funil (Kanban)

O Funil de Vendas ajuda a visualizar o progresso dos seus leads.

1. Acesse o menu **Kanban**.
2. Cada coluna representa uma etapa (ex: Prospecção, Negociação, Fechado).
3. Para mover um cliente, basta **clicar e arrastar** o card do contato de uma coluna para a outra.
4. As alterações são salvas em tempo real para toda a equipe.

---

## 7. Como Arquivar/Descartar um Contato Desqualificado

Mantenha sua base limpa removendo ou arquivando quem não tem perfil de compra.

* **No Chat**: Clique no ícone de "Resolver" (Check verde) para encerrar o ticket e enviá-lo para a aba de "Resolvidos".
* **No Contato**: Vá em **Contatos**, selecione o contato e clique no ícone de **Arquivar** ou **Excluir** (lixeira).
* *Dica: Use a tag "Desqualificado" antes de arquivar para fins de relatórios.*

## 8. Boas Práticas para o Funcionamento do CRM

1. **Sempre resolva Tickets**: Nunca deixe conversas abertas sem necessidade; isso polui a tela de atendimento.
2. **Use Tags religiosamente**: Sem tags, você não consegue filtrar quem são seus melhores clientes depois.
3. **Atualize o Kanban diariamente**: Uma espiada no funil garante que nenhum negócio seja esquecido.
4. **Resuma a Conversa**: Use o campo de "Observações" no contato para anotar detalhes importantes de ligações ou reuniões externas.

## 9. Monitoramento e Reportagem de Bugs

Como administrador, você tem ferramentas para garantir que o sistema esteja saudável.

### Como Monitorar

* **Painel Administrativo**: Use o menu **Métricas do Sistema** para ver o volume de mensagens e a saúde global.
* **Performance**: Use o menu **Performance** para verificar se o servidor está lento ou com uso alto de memória.

### Como Reportar um Erro

Se você encontrar um problema técnico:

1. Acesse **Erros do Servidor** no menu administrativo.
2. Localize o erro mais recente (geralmente marcado como CRITICAL ou HIGH).
3. Clique em **Ver Detalhes** para ver o "Stack Trace" (o código do erro).
4. Tire um print ou copie esses dados e envie para o time de suporte/desenvolvimento. Isso agiliza a correção em 90%.
